## Projects

### Velora (in development)

A music client for your own library, running as a web app, an Electron desktop app and an
Android build from one React + TypeScript codebase. Talks to my own self-hosted Node backend,
to the Subsonic family (Navidrome, Airsonic, gonic, Ampache), to Jellyfin/Emby, or to a purely
local library with no server at all. Themeable down to the token layer, with a sandboxed plugin SDK.

### [EzReplay Pro](https://ezreplay.uplift-beyond.de)

Offline-first video analysis in the browser. Local files or YouTube, timestamped markdown notes,
export and import of whole sessions. No backend, no account, nothing leaves your machine.

### Specula (planned)

Self-hosted Minecraft server management with a Discord bot attached: multi-server dashboard,
live console, whitelist flow, backups. React + Fastify + SQLite, brought up by a single
docker-compose on a fresh VPS.
